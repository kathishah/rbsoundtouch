rbsoundtouch
============

An unfinished 2012-2013 experiment: Ruby bindings for the [SoundTouch](http://www.surina.net/soundtouch/) audio library, generated with [SWIG](http://www.swig.org). `soundtouch.i` is the SWIG interface (including a typemap that turns a Ruby array of samples into a C++ buffer), `extconf.rb` builds the C++ extension, and `notes.md` is the lab notebook of how it was set up on Ubuntu. `lib/bpm_detect/` is a partial Ruby port of SoundTouch's BPM detector.

**Status and stance:** abandoned and incomplete. Not touched since January 2013. The wrapper builds only against the Debian/Ubuntu header layout, and the BPM detector does not work (it was never finished). Pull requests are not expected. Use at your own risk.

**Third-party code:** SoundTouch is by Olli Parviainen and is licensed under the LGPL 2.1. `lib/bpm_detect/` is a port of its `BPMDetect.cpp`, so it is derived from that code and stays under the LGPL 2.1. This repository has no licence file of its own; do not read the absence of one as a permissive licence. `soundtouch_wrap.cxx` is generated by SWIG 2.0.7. An article PDF and SWIG manual pages that earlier commits contained, and compiled build output, have been removed from the current tree (they remain in the git history).
